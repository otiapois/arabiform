# ArabiForm

Browser-local **CSV / Excel → Arabic & Unicode AcroForm Batch PDF Studio** with deterministic HarfBuzz/fontkit shaping, automatic ink-bounds baseline centering, strict leading-zero preservation (`00123`), live PDF preview, and `CSP: connect-src 'none'` verifiable zero-upload privacy.

- **Project Manager & Final Acceptor**: Antigravity / Gemini
- **Lead Executor**: Codex CLI (5-Worker Agent Team + 3-Loop engineering governance)
