# ArabiForm · 20-second synthetic demo

Record the built workbench with `npm run build` and `npm run preview`. Load the synthetic landscape badge PDF (`fixtures/m2/landscape-badge.pdf`) and its roster (`fixtures/m2/badge-roster.csv`). Keep the minimum font size at 8 pt and select row 1. For this fixture the preflight size for `Name` is 7.58 pt. The built-in **Try Synthetic Arabic Sample** loads a different roster. Its final row is deliberately too long and demonstrates editing the cell text.

The timestamps are editing targets for the finished clip. Cut idle intervals between actions and leave the actual diagnostic and preview visible long enough to read.

## English community post

**Title**

Preview Arabic names before exporting a batch of PDF forms

**Post**

ArabiForm fills editable PDF forms from CSV or Excel in your browser. When a name is too large for its field, the preview highlights the field and shows the font size that would fit when one is available. In this short demo, a fictional badge roster shows how to apply the suggested size, check the preview, and download the PDFs. Template and roster processing happens on your device.
