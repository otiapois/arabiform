# Code Standards (ArabiForm)

Adapted from `yetone/magpie/docs/code-standards.md` + lessons already proven in `ImportMedic` M1 & M1.5.

| Rule | What Reviewer Checks |
| --- | --- |
| **Check XFA / Encryption / Signatures BEFORE `getForm()`** | `pdf-lib`'s `getForm()` can strip `/XFA` silently. Always inspect PDF catalog/AcroForm dictionary directly at intake and fail-closed with a clear user message. |
| **True Ink BBox Baseline (Zero Silent Arabic Clipping)** | Never place Arabic text using naive `fontSize * 0.2` heuristics. Shape via `fontkit`, sum exact glyph advances, `xyOffset`, and true ink `yMin`/`yMax` (including harakat & descenders), verify fit against inner rect minus border/padding, and flag anything below `minFontSize`. |
| **Canonical Field Multi-Widget Atomicity** | A single PDF field can have multiple widgets across pages (including `/Rotate 90/180/270` pages). Lay out EVERY widget independently; if ANY widget fails bounds, flag the whole field rather than partially writing half the pages. |
| **Strict Text Preservation for Leading Zeros** | Parse CSV and Excel ID/code columns without numeric coercion (`00123` MUST stay `"00123"`). Never convert string IDs through `Number()`. |
| **Untouched Field Invariance** | Unmapped fields retain exact original `/V` and `/AP` streams. Tests must include a populated unmapped sentinel field (e.g. `KEEP 00109`) and verify byte/value preservation. |
| **Zero External Runtime Requests** | Bundle all fonts, `pdf.js` worker, and sample fixtures locally. Zero Google Fonts, zero analytics beacons, zero network calls during processing; verified in Playwright network listener and `dist/_headers` CSP `connect-src 'none'`. |
| **Atomic Scope + Sibling Grep** | Fixes for one input format (CSV vs XLSX) or one output mode (ZIP vs Merged PDF) must grep and check the sibling path in the same change. |
| **Real Environment Red -> Green** | Every layout/PDF bug fix adds a failing fixture + PyMuPDF visual/readback test before marking green. Full suite (`typecheck + test + build + test:e2e`) must pass on `main`. |
| **Close the E2E preview listener** | Use the production preview handler. Let the test runner own and close the server handle, then verify the run exits and the test port refuses new connections. |
| **Check populated results at 390 px** | Load actual files or a completed sample on the mobile viewport. Measure the document width and inspect the visible bounds of the primary filename and diagnostic in their container. Verify both reading directions on bilingual screens. [Mobile overflow evidence from three cycles](../LESSONS.md#seeded-from-m1-static-preview--mobile-overflow-audit-2026-11-26) |
| **Isolate Latin file extensions in RTL text** | Give the extension and its parentheses an explicit LTR isolation boundary. In Edge, measure the dot, letters and parentheses of related download and file-picker labels on desktop and mobile. Keep Arabic sentence punctuation within its sentence when an isolated folder name follows. Check the accessible names of existing controls. [PDF filenames](../tests/e2e/m3-pro.spec.ts) · [XLSX label](../tests/e2e/m7-power-editor.spec.ts) · [ZIP button](../tests/e2e/m16-grouped-designer.spec.ts) · [Custody and draft controls](../tests/e2e/m17-studio-verifier.spec.ts) · [Packet ZIP and JSON controls](../tests/e2e/m21-packets.spec.ts) |
| **Compare editable and printed PDF pixels** | Reopen the delivered editable and flattened outputs, render the same page at 4×, and compare the full raster. For an intentional stamp, first compare the unmarked pages, then measure the stamp and compare all pixels outside its rectangle. Reject printing when a visible widget lacks the required active appearance and preserve the editable export. [Choice failures](../tests/core/choices.test.ts) · [Native print checks](../scripts/verify-pdf-pixels.py) · [Actual stamped ZIP members](../tests/e2e/m17-printed-qr.py) |
| **Recover the Windows pixel verifier at the failing stage** | If tsx reports `uv_os_get_passwd ENOMEM` while preparing its temp directory, save the startup error. Rerun `npm run verify:pixels` in an approved local environment with the same revision, D-drive inputs and temp paths. Verify the newly generated pixel report. |
| **Measure a timeout at the individual test** | Preserve the failing log and rerun the affected case to distinguish a slow operation from a failed assertion or missing input. Keep the inputs, case counts and assertions intact. Adjust the measured case’s time budget and confirm the full suite on the frozen revision. [M6, M11 and M18 evidence](../LESSONS.md#m6-本机验收的超时与退出码) |
| **Observe transient batch progress before starting the operation** | Attach the browser observer to a persistent ancestor that contains the live status or progress meter throughout source replacement. Record the actual intermediate announcement or nonzero value and independently assert the final ready and flagged totals. [M8, M14 and M19 evidence](../LESSONS.md#从稳定的工作台节点记录短暂的预检阶段2026-11-28) |
