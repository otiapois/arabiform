## Local Batch Drafts

- **Save Draft (.json)** downloads a versioned local file with the effective cell edits, including transformations, the applied hygiene summaries, and mapping and output settings. The draft format remains v1 and embeds v5 settings with an active watermark or v4 settings with the watermark off. Both settings versions load under the same source matching rules. A draft may contain roster cell values. Source PDF, roster, and font bytes are supplied locally when restoring. The draft is persisted in the downloaded file only, with no cloud storage or `localStorage`.
- **Load Draft (.json)** validates the JSON before applying settings. The active PDF and roster must match the stored SHA-256 fingerprints and the expected fields, worksheet, ordered columns, and row count. If the draft used a custom font, the selected font bytes must also match the stored SHA-256 fingerprint. A mismatch reports a local error before applying draft changes.

## Static Pre-Rendered SEO Routes (Strictly <= 5 per `SEO完整策略.md`!)
1. `/` — Main workbench for filling AcroForm PDFs from CSV or Excel.
2. `/arabic-pdf-form-filler` — Focused English landing page (`fill pdf from csv arabic`, comparison against WinAnsi/clipping failures)
3. `/ar/pdf-mail-merge` — Clean Arabic RTL landing page (`dir="rtl"`, concise verified Arabic UI/copy, clearly marked for native reader verification before launch)
4. `/preserve-leading-zeros-pdf` — Focused page on preserving `00123` / `00007` IDs from CSV & Excel into PDFs
5. `/privacy-and-proof` — Browser-local processing and supported PDF types, with steps to inspect a synthetic row, correct its field, and compare the PDF preview.

The English Arabic PDF guide and the Arabic mail merge guide offer an interactive comparison with a clipped baseline and ink-bounds placement. Both states use the labeled synthetic specimen `بَنِي يَمَن / سَلْمَى بِنْت يَاسِين`. The controls support pointer and keyboard input. The web display uses local assets. Verify that initial idle visits to `/`, `/arabic-pdf-form-filler`, and `/ar/pdf-mail-merge` defer template inspection, PDF engine and preview code, worker bundles, and PDF-embedding fonts until the corresponding action. The page summaries and guide copy are authored in `scripts/prerender.mjs` and carried into the workbench from the static page.

## Cloudflare Pages Production Readiness
- Build outputs `dist/_headers` with `Content-Security-Policy` including `connect-src 'none'`, `worker-src 'self'` and `form-action 'none'`, plus `X-Content-Type-Options: nosniff` and `Referrer-Policy: no-referrer`.
- Check that `dist/` contains precisely the five HTML routes above with JSON-LD and no named `<form>` elements. The Arabic route declares `lang="ar" dir="rtl"`. `dist/sitemap.xml` and `dist/robots.txt` use the `SITE_URL` origin, with `https://arabiform.example` as the local default.
- CI runs `npm run verify:release` immediately after `npm run build`. The gate checks the five routes, sitemap, response headers, included license notices, and each route's entry JavaScript budget of under 300,000 raw bytes and 95,000 gzip bytes. The M8 entry-size target is below 285,000 raw bytes and 89,000 gzip bytes.
