# Subsystem Design References (ArabiForm)

| Subsystem | Scope | Contract |
| --- | --- | --- |
| PDF & Font Shaping Engine (`src/core/pdf/`) | AcroForm inspection, preview widget geometry, widget capacity and print-margin clearance, text and checkbox mapping, dropdown and radio choices, bundled and local font shaping and ink bounds, per-text-field alignment, numeral conversion and typography, mixed-widget preservation, editable and flattened PDF exports, optional A4 2-up merged printing and bilingual cover, watermarks, local vector QR stamps and approval seals, roundtrip readback | [pdf-engine.md](pdf-engine.md) |
| Bilingual Starter Templates (`src/core/studio/`) | Generate four editable AcroForm templates with configurable headers and matching starter CSVs | [pdf-engine.md](pdf-engine.md#bilingual-starter-templates) |
| Flat PDF Field Authoring (`src/core/designer/`) | Check flat source eligibility, convert page geometry, create text fields, checkboxes, dropdowns and radio groups, and save or restore source-bound layout JSON | [pdf-engine.md](pdf-engine.md#flat-pdf-field-authoring) |
| Grouped Batch Exports (`src/core/export/`) | Plan ZIP subfolders and per-folder filenames from a roster column, retain original row positions, and split merged print PDFs with a custody receipt | [roster-mapper.md](roster-mapper.md#grouped-output-paths) · [pdf-engine.md](pdf-engine.md#custody-manifest) |
| Multi-Template Packet Assembly (`src/core/packet/`) | Preflight two to four ordered templates against one roster with per-template mappings, hold incomplete recipients, and write flattened packets with an optional bilingual index, grouped ZIP, and unsigned byte manifest | [pdf-engine.md](pdf-engine.md#multi-template-packet-assembly) · [web-preview-seo.md](web-preview-seo.md#assemble-packets) |

| Browser Batch Worker (`src/core/worker/`) | Local preflight and export jobs, 25-row chunks, on-demand PDF generation for all ready rows or a selected subset, row progress, cancellation, and stale-result isolation | [pdf-engine.md](pdf-engine.md) |
| Custody Manifest (`src/core/audit/`) | Local SHA-256 fingerprints of original sources and exported PDFs, grouped member paths, per-group split ZIP receipt, XLSX worksheet name after a tab switch, export scope and original row numbers, and optional source fingerprint prefixes on covers | [pdf-engine.md](pdf-engine.md#custody-manifest) |
| Offline Receipt Verification (`src/core/custody/`) | Compare delivered PDF bytes or structured QR membership against a supplied unsigned batch receipt | [pdf-engine.md](pdf-engine.md#offline-receipt-verification) |
| Local Batch CLI (`src/core/cli/`, `scripts/arabiform-cli.ts`) | Offline scripting for starter templates, preflight, filling, packet assembly, extraction and receipt verification using the same engines as the browser workbench | [cli-automation.md](cli-automation.md) |
| Bulk Filled PDF Extraction (`src/core/extractor/`) | Read saved AcroForm values from 1–200 PDFs, report per-file failures and schema differences, and write CSV, text-valued XLSX and an extraction custody receipt | [pdf-engine.md](pdf-engine.md#bulk-filled-pdf-extraction) |
| Roster Ingestion & Auto-Mapping (`src/core/roster/`) | CSV (`papaparse`) and XLSX ingestion, visible worksheet inspection and selection, encoding and leading-zero preservation, spreadsheet source warnings, opt-in column hygiene with Undo, auto-mapping, local virtual columns, QR payload patterns and safe filenames | [roster-mapper.md](roster-mapper.md) |
| Conditional Field Rules (`src/core/rules/`) | Ordered field overrides from effective roster cells, evaluated before PDF formatting and preflight, with v11 preset and audit support | [roster-mapper.md](roster-mapper.md#conditional-field-rules) · [pdf-engine.md](pdf-engine.md#responsibilities) · [cli-automation.md](cli-automation.md#conditional-rule-walkthrough--تجربة-القواعد-الشرطية) |
| Portable Batch Drafts (`src/core/draft/`) | Local JSON serialization and validation, source and font matching, edits, cleanup summaries, field mapping, and output settings | [web-preview-seo.md](web-preview-seo.md#local-batch-drafts) |
| Local Workbench, Live PDF Preview & Static SEO (`src/web/`) | Browser-local workbench, `pdfjs-dist` raster preview with keyboard-accessible widget selection, boundary-row jumps and two-row comparison, row fixes and subset selection, keyboard navigation and help, template capacity table and CSV, print settings, approval seal preview and margin guide, audit and custody downloads, mapping presets, synthetic workflows, five static routes, production CSP, Playwright Edge E2E | [web-preview-seo.md](web-preview-seo.md) |
