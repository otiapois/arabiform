# ArabiForm test fixtures

The tracked fixtures are synthetic and deterministic. Run `npm run generate:fixtures` to regenerate them offline from the installed lockfile dependencies. `npm run generate:fixtures -- --check` compares every generated byte with the tracked copies.

## Workshop attendance demo

The US Letter PDF `golden/template.pdf` has five populated AcroForm widgets. These coordinates use the bottom-left origin of the unrotated page, in PDF points.

| Field | x | y | Width | Height | Initial value |
| --- | --: | --: | --: | --: | --- |
| `Name` | 64 | 536 | 484 | 40 | Sample participant |
| `ID` | 64 | 436 | 218 | 36 | `00000` |
| `Title` | 310 | 436 | 238 | 36 | Workshop participant |
| `Notes` | 64 | 280 | 484 | 102 | Two lines of session notes |
| `Sentinel` | 64 | 172 | 250 | 34 | `KEEP 00109` |

`Notes` has the PDF multiline flag. The embedded Noto Sans font supplies the printed labels and original widget appearances. `Sentinel` has an original appearance stream and remains unmapped in demo tests.

- `golden/roster.csv` and the `Roster` worksheet in `golden/roster.xlsx` contain the same five rows. They include text IDs `00123` and `00007`, the mixed-script ID `AR-00042 / ق`, Arabic names with full diacritics, mixed Arabic and Latin text, and multiline notes. The first four rows fit. The final row overflows `Name` at 8 pt. Replacing its name with `ليلى حسن` resolves the overflow.
- The workbook's `Numeric IDs` worksheet includes text ID `00123`, numeric ID `7`, a numeric cell formatted as `1.23457E+11`, and the literal text `1.23457E+11`.

## M2 synthetic forms

Each fixture under `m2/` has a distinct form and a `KEEP 00109` unmapped field. `npm run verify:pixels` fills each form and checks exact values, original appearance streams, and ink bounds at 4× using a SHA-256-named copy of the source bytes.

| PDF | Scenario |
| --- | --- |
| `hr-onboarding.pdf` | Required employee name, leading-zero ID, date, and mixed RTL and Latin text |
| `clinic-intake.pdf` | International phone with grouped digits and two languages separated by a newline |
| `bilingual-certificate.pdf` | Centered names, paired brackets, Arabic-Indic digits, and right-aligned record number |
| `landscape-badge.pdf` | Page `/Rotate 90` and widget `/MK /R 90`, with the exact minimum font adjustment below |
| `access-code.pdf` | A valid leading-zero code in a narrow `/MaxLen` field, and separate refusals for overlength and comb fields |
| `dispatch-header.pdf` | One canonical header across three pages with different rotations and widget geometry |
| `mailing-address.pdf` | Multiline field with explicit line breaks, wrapping, and Arabic marks |
| `remittance-slip.pdf` | Right-aligned beneficiary, mixed-script reference, and Arabic-Indic amount |

Use `m2/badge-roster.csv` with `m2/landscape-badge.pdf`. The one synthetic record flags `Name` at 8 pt and passes at the indicated 7.58 pt with the canonical field value and `00007` badge ID preserved.

## Optional public baselines

Store official blank downloads in a local directory and run `node scripts/verify-public-templates.mjs <directory>` to verify their hashes and PDF field inventory. The default directory is `test-results/public-templates`. The probe skips an absent download and reports the number actually verified. The tracked synthetic suite runs independently of these downloads.

## M3 mixed-widget samples

`m3/clinic-consent-mixed.pdf` is a synthetic blank clinic form with Arabic-ready Name and Latin ID fields, a Consent checkbox repeated across two widgets, an already-checked Verified checkbox, a selected Contact radio group, a Clinic dropdown, and the original `KEEP 00109` sentinel.

`m3/clinic-consent-roster.csv` contains an affirmative row, a negative row, and an invalid Consent value for preflight. `m3/clinic-consent-formulas.xlsx` includes a cached boolean and an uncached formula in column C.

The pixel verifier checks both checkbox transitions, all preserved fields and a custom Noto Naskh Arabic TrueType render. Set `ARABIFORM_CUSTOM_CFF_FONT` to a local Latin OpenType CFF font for the optional CFF and merged-print comparison.
