# Changelog / سجل التغييرات

## English

| Version | Changes |
| --- | --- |
| v1.2.0 (M12) | Add an optional per-record vector QR stamp to merged printable PDFs and flattened PDFs in ZIP. Set a corner, size, and roster pattern, then preview the selected row's QR locally. Choose the page language, English, Arabic, or both for the print cover. The bilingual cover puts headings and counts side by side over one shared index. Version 7 presets and local draft settings store the QR and cover language settings. Versions 1–6 still import. |
| v1.1.0 (M11) | Click a field in the PDF preview or activate it with the keyboard to focus the matching mapping control. Focusing that control highlights the field in the preview and opens its page when needed. Use locally computed row numbers, four-digit-minimum serials, or Gregorian dates with Western or Arabic-Indic digits in text fields and filenames. Version 6 presets and draft settings store the virtual mappings. Preset versions 1–5 still import. |
| v1.0.0 (M10) | Select specific ready rows or all ready matches across the filtered queue. The selection scopes ZIP, merged PDF and its cover index, preflight audit, and the custody manifest. The receipt records the export scope and original roster positions. Open the keyboard shortcuts dialog with `?` or its button, navigate matching rows with the arrow keys, and press `Esc` to return focus after closing the dialog. Added a strict release command that accepts the intended origin as an argument. |
| v0.9.0 (M9) | Download a separate JSON custody manifest with SHA-256 hashes of the source files and the PDFs generated by successful exports. Compare the full hashes to check that files match the bytes recorded in the receipt. Optionally print short source fingerprints on the merged PDF cover. The print-margin advisory identifies mapped widgets less than 9 pt from the nearest page edge, with the field, page, edge, and clearance. Ready rows remain available for export. |
| v0.8.0 (M8) | Inspect template field and widget dimensions, rotation, `/MaxLen`, and estimated Arabic and Latin text capacity before choosing a roster. Download the capacity report as CSV. Add an optional English, Arabic, or custom stamp to the merged printable PDF or flattened PDFs in ZIP. Version 5 mapping presets and local drafts save active watermark settings. Older presets still import. The local worker processes 500-row batches in chunks of 25 with progress and cancellation. |
| v0.7.0 (M7) | Preview and apply optional Arabic text cleanup or literal find and replace in selected roster columns. Undo the last transform. Set text-field alignment to Auto, Right (RTL), Left (LTR), or Center. Version 4 mapping presets save explicit alignment, and versions 1–3 still import. Save edits, applied cleanup summaries, mapping, and output settings to a local JSON draft and reopen it with the matching PDF, roster, and worksheet. The PDF preview has Fit, 100%, 125%, and 150% zoom and a page strip that marks flagged pages. The Arabic source hint displays `.xlsx` with its dot on the left. |
| v0.6.0 (M6) | Added an optional English or Arabic cover for the merged printable PDF. It includes a batch summary and a paginated index with the final filenames and page ranges. Mapping presets save the cover setting in version 3 and still read versions 1 and 2. The English and Arabic guides add an interactive synthetic ink-bounds specimen. The sample gallery shows four workflows, including the landscape badge to try the batch font-size suggestion. |
| v0.5.0 (M5-RC) | The queue shows why a filename was adjusted before export. Slash focuses search, and Escape cancels the current edit and restores focus. The Arabic page loads display fonts locally and defers packaged PDF font data until preflight. Added a release bundle check. |
| v0.4.0 (M4) | Added dropdown and radio mappings, optional flattened PDFs within ZIP, and preview navigation to the first page with a flagged field. |
| v0.3.0 (M3) | Added checkbox mapping, local TTF and OTF upload with glyph checks, and warnings for mapped Excel formula cells. Unmapped widgets keep their original values and appearances in editable PDFs. |
| v0.2.0 (M2) | Moved batch checks and exports to a cancellable local worker. Added mapping presets, queue search, filename protections, and more detail on text that does not fit. |
| v0.1.0 (M1) | Added browser-local filling of AcroForm text fields from CSV or XLSX, Arabic and Unicode preview, row fixes, and ZIP, printable PDF, and audit downloads. |

## ملخص بالعربية

- **v1.2.0 (M12)** أضف رمز QR اختياريًا لكل سجل في ملف PDF المدمج للطباعة وفي الملفات المسطّحة داخل ZIP. اختر زاوية الرمز ومقاسه ونمط النص الذي سيحمله، ثم عاين رمز الصف المحدد محليًا. اختر للغلاف لغة الواجهة أو الإنجليزية أو العربية أو اللغتين معًا. يعرض الغلاف الثنائي العناوين والأعداد جنبًا إلى جنب فوق فهرس واحد. يحفظ الإصدار 7 إعدادات الرمز ولغة الغلاف، سواء حُفظت الإعدادات وحدها أو ضمن مسودة محلية. يظلّ استيراد الإصدارات من 1 إلى 6 متاحًا.
- **v1.1.0 (M11)** انقر على حقل في معاينة PDF أو فعّله بلوحة المفاتيح للانتقال إلى إعداد الربط الخاص به. عند التركيز على إعداد الربط، يبرز الحقل في المعاينة وتُفتح صفحته عند الحاجة. استخدم رقم الصف أو رقمًا تسلسليًا من أربع خانات على الأقل أو تاريخًا ميلاديًا بأرقام غربية أو عربية هندية في الحقول النصية وأسماء الملفات. تُحسب هذه القيم محليًا. تُحفَظ روابط الأعمدة المحسوبة في الإصدار 6 من الإعدادات، سواء حُفظت الإعدادات وحدها أو ضمن مسودة. يظل استيراد إصدارات إعدادات الربط من 1 إلى 5 متاحًا.
- **v1.0.0 (M10)** حدّد صفوفًا جاهزة بعينها أو كل الصفوف الجاهزة المطابقة للبحث والتصفية. يحدّد اختيارك ما يدخل في أرشيف ZIP وملف PDF المدمج وفهرس غلافه وتقرير الفحص وبيان سلسلة الحيازة. يسجّل البيان نطاق التصدير وأرقام الصفوف الأصلية. افتح نافذة اختصارات لوحة المفاتيح بزرها أو بالضغط على `؟`، وتنقّل بين الصفوف المطابقة بمفتاحَي السهم، واضغط `Esc` لإغلاق النافذة وإعادة التركيز إلى موضعه السابق. يقبل أمر التحقّق الصارم من الإصدار عنوان الموقع المقصود مباشرةً.
- **v0.9.0 (M9)** نزّل بيان سلسلة الحيازة في ملف JSON مستقل يضمّ بصمات SHA-256 للملفات المصدرية وملفات PDF الناتجة عن عمليات التصدير الناجحة. قارن البصمات الكاملة للتحقّق من تطابق محتوى الملفات مع النسخ التي سُجّلت بصماتها في البيان. يمكنك طباعة بصمات مصدرية مختصرة على غلاف ملف PDF المدمج. يحدّد تنبيه هامش الطباعة كل موضع لحقل مرتبط يبعد أقلّ من 9 نقاط عن أقرب حافة للصفحة، ويبيّن اسم الحقل ورقم الصفحة والحافة والمسافة. يظلّ تصدير الصفوف الجاهزة متاحًا.
- **v0.8.0 (M8)** افحص أبعاد الحقول ومواضع ظهورها وزوايا دورانها وحدّ `/MaxLen` وسعتها التقريبية للنص العربي واللاتيني قبل اختيار جدول البيانات. نزّل تقرير سعة الحقول بصيغة CSV. أضف علامة مائية بالعربية أو الإنجليزية، أو بنصّ تختاره، إلى ملف PDF المدمج للطباعة أو الملفات المسطّحة داخل ZIP. يحفظ الإصدار 5 من إعدادات الربط خيار العلامة المائية، وتحفظه المسودات المحلية أيضًا. تستمر الأداة في استيراد الإصدارات السابقة. يعالج عامل المتصفح دفعات من 500 صف على مجموعات من 25 صفًا مع عرض التقدّم وإتاحة الإلغاء.
- **v0.7.0 (M7)** يمكنك معاينة تنقيح النص العربي أو البحث والاستبدال الحرفي في أعمدة تحدّدها، ثم تطبيق التغييرات والتراجع عن آخر عملية. يمكنك اختيار المحاذاة التلقائية لكل حقل نصي أو ضبطها إلى اليمين أو اليسار أو الوسط. يحفظ الإصدار 4 من إعدادات الربط المحاذاة المحدّدة، ويستمر دعم استيراد الإصدارات 1 إلى 3. احفظ تعديلات الخلايا وملخّص عمليات التنقيح وإعدادات الربط والإخراج في مسودة JSON محلية، واستعدها باستخدام ملف PDF وجدول البيانات وورقة العمل المطابقة. تتيح المعاينة ملاءمة الصفحة للمساحة المتاحة أو عرضها بنسبة 100٪ أو 125٪ أو 150٪، ويشير شريط الصفحات إلى الصفحات التي تحتاج إلى مراجعة. تظهر نقطة امتداد `.xlsx` على يسار الأحرف في تلميح اختيار الجدول بالعربية.
- **v0.6.0 (M6)** غلاف اختياري بالعربية أو الإنجليزية لملف PDF المدمج للطباعة. يعرض ملخّص الدفعة وفهرسًا قد يمتدّ إلى عدّة صفحات، وفيه أسماء الملفات النهائية ونطاقات الصفحات. يحفظ الإصدار 3 من إعدادات الربط خيار الغلاف مع استمرار دعم استيراد الإصدارين 1 و2. يتضمّن الدليلان العربي والإنجليزي مثالًا اصطناعيًا تفاعليًا يقارن طريقتَين لوضع النص داخل الحقل. يعرض المعرض أربع عينات، منها بطاقة الزائر الأفقية لتجربة اقتراح حجم الخط للدفعة.
- **v0.5.0 (M5-RC)** يظهر سبب تعديل اسم الملف قبل التنزيل. ينقل زر الشرطة المائلة التركيز إلى البحث، ويلغي Escape التعديل الجاري ويعيد التركيز إلى زر التحرير. تُحمَّل خطوط عرض الواجهة محليًا، وتُؤجَّل بيانات خطوط PDF إلى الفحص المسبق. أضيف فحص لملفات الإصدار.
- **v0.4.0 (M4)** ربط القوائم المنسدلة وأزرار الاختيار، وخيار تسطيح ملفات PDF داخل ZIP، والانتقال مباشرة إلى أول صفحة فيها حقل يحتاج إلى مراجعة.
- **v0.3.0 (M3)** ربط خانات الاختيار، ودعم خطوط TTF وOTF المحلية مع التحقق من المحارف، وتنبيهات لصيغ Excel في الخلايا المرتبطة. تحتفظ الحقول غير المرتبطة بقيمها ومظهرها في النسخ القابلة للتعديل.
- **v0.2.0 (M2)** فحص الدفعات وتصديرها في عامل محلي قابل للإلغاء، وحفظ إعدادات الربط، والبحث في الصفوف، وحماية أسماء الملفات، وتفاصيل إضافية عن النص الذي يتجاوز مساحة الحقل.
- **v0.1.0 (M1)** تعبئة حقول AcroForm النصية من CSV أو XLSX داخل المتصفح، ومعاينة النص العربي وUnicode، وتصحيح الصفوف، وتنزيل ملفات ZIP وPDF للطباعة وتقارير الفحص.
