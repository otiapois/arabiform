# Changelog / سجل التغييرات

## English

| Version | Changes |
| --- | --- |
| v2.7.0 (M27) | Open **Compare batches** in the English or Arabic workbench to classify two local PDF ZIP exports by relative path and exact SHA-256. Review old and new saved field values in modified AcroForms and print only the modified and added PDFs. Download the delta ZIP, CSV and JSON audits, and a one-page bilingual summary of counts and estimated sheet savings. The offline CLI supports `--mode diff-batch`. [Batch comparison and synthetic demo](README.md#compare-batches) |
| v2.6.0 (M26) | In **Data validation**, apply required, IBAN Mod-97, Gregorian ISO date, exact digit count, email syntax, and allowed-list rules to roster columns. The review queue and CSV and JSON audits identify the failing row, column, rule, and reason. Fix a row inline to bring it back into the ready scope. Try the synthetic GCC payroll demo, or reuse the rules from a version 13 mapping preset with the offline CLI. Versions 1–12 still load. `fill --strict` holds the whole batch when a row fails. [Data validation walkthrough](README.md#data-validation) |
| v2.5.0 (M25) | Download locally prepared bilingual email drafts, one per ready row in scope, with the row’s exact PDF attached. Check recipients, filenames and SHA-256 hashes in the dispatch ledger. Mask selected text fields for review and identify masked exports in the custody manifest. The local CLI also supports both workflows. [Email drafts](README.md#offline-email-drafts) · [Redacted review](README.md#redacted-review-copies) |
| v2.4.0 (M24) | Place up to four one-page records on each A4 sheet with corner crop marks, optional center guides and cut-and-stack order. The print estimate shows actual sheet savings against 1-up for the current scope, including cover pages and split groups. With the cover off and every slot filled, 4-up uses 75% fewer sheets. Download a one-page bilingual print-shop certificate with the SHA-256 of the exact combined merged PDF and the preflight fit result for its included rows. Use version 12 presets for 4-up settings or run `fill --imposition 4-up --print-certificate` locally. [Print-shop certificate and workflow](README.md#print-shop-certificate) |
| v2.3.0 (M23) | Open **Compare templates** to check two AcroForm revisions for added and removed fields, type changes, smaller widgets, character limits, and choice changes. Map renamed fields to compatible targets and download a migrated v1–v11 preset when its references pass validation. Save CSV and JSON migration reports with both template fingerprints, or open the revised PDF and migrated preset in **Fill PDFs** for roster preflight. The offline CLI supports `--mode diff-template`. [Template comparison workflow](README.md#compare-templates) |
| v2.2.0 (M22) | Open **Conditional rules** in Fill PDFs to set or clear text, change checkboxes, or select existing PDF choices from roster values. Reorder rules to choose which matching rule applies to each field, see how many rows it applies to, and review the result in the PDF preview. Version 11 mapping presets carry the ordered rules into the offline CLI with `--preset`. Versions 1–10 still load. Preflight audits identify the rule applied to each affected field. [Conditional rules workflow](README.md#conditional-rules) |
| v2.1.0 (M21) | Use **Assemble packets** in English or Arabic, or `--mode packet` in the offline CLI. Order two to four AcroForm templates, map each to one shared CSV or Excel roster, and export one flattened PDF per ready person. A failed field in any template holds that person's packet while other ready people can still be exported. Add a bilingual index with actual start pages, group ZIP members by a roster column, and save an unsigned SHA-256 manifest of the inputs and exported PDFs. [Packet workflow](README.md#assemble-packets) |
| v2.0.0 (M20) | Set the numeral script, line height, and inner padding per mapped text field. Digit conversion preserves leading zeros and takes effect in both the field value and the rendered text. Add an optional bilingual vector approval seal with an issue date to flattened ZIP members and merged printable PDFs, including split and 2-up output. Preview its placement and change corners if the seal overlaps a visible field or QR stamp. Save both features in version 10 mapping presets for use in the workbench or the offline CLI with `--preset`. Versions 1–9 still import. |
| v1.9.0 (M19) | Jump to the longest mapped text, smallest rendered font, or first flagged row. Compare two rows in the English or Arabic workbench with independent PDF previews. Ready rows show the smallest painted text size and the tightest ink-to-field clearance when available. Flagged rows show the original template and field issues. The print sheet estimator updates with the ready selection, layout, cover, and grouping. It compares 1-up with 2-up when supported and includes separate totals for combined and split merged PDFs. |
| v1.8.0 (M18) | Run local PDF batches from a source checkout with `npm run arabiform-cli --`. Use `studio` for bilingual starter files, `preflight` for CSV and Excel diagnostics, `fill` for editable and flattened ZIPs and a merged print PDF, `extract` for saved form values, and `verify` for PDF byte or custody QR checks against an unsigned receipt. The workbench's **Local CLI command** provides a copyable `fill --strict` command, which blocks export when a row fails. The CLI uses exit codes `0` for clean results, `2` for flagged or blocked results, and `1` for usage or I/O errors. [Commands, flags, and receipt format](docs/subsystems/cli-automation.md) |
| v1.7.0 (M17) | Create a fillable Arabic and English completion certificate, employment verification letter, clinic consent form, or visitor badge. Set the organization name, subtitle, palette, and header language, then preview the PDF, download its matching starter CSV, or open the PDF in Fill. **Verify receipt** compares exact delivered PDF bytes or the membership of a pasted custody QR record against a supplied, unsigned batch manifest. Enable custody QR in print settings to record stamped rows in new receipts. Existing custom QR patterns, saved settings, and earlier PDF digest receipts remain supported. |
| v1.6.0 (M16) | Group the individual PDF ZIP by a roster column. Review group folders and ready-row counts before downloading, and find exact member paths in the preflight audit and custody manifest. Export a split ZIP with one merged printable PDF per group, group-specific cover indexes, and a `batch-custody.json` receipt. Each group's PDF supports the selected cover language, print watermark, local vector QR stamp, and A4 2-up for single-page templates. Version 9 presets store the grouping column, and versions 1–8 still import. In **Design fields**, add dropdown options and radio buttons that share one field name and have distinct export values. Save their settings and positions in a reusable layout or fill the generated AcroForm and extract the choices from the editable output. |
| v1.5.0 (M15) | Add text fields and checkboxes to a flat PDF in the English or Arabic **Design fields** workbench. Set each field's page and position, and configure alignment, font size, multiline text, and length limits for text fields. Save or reload a field layout as JSON tied to the source PDF's SHA-256. Download a reusable AcroForm template or open it directly in **Fill PDFs** for roster mapping, Arabic ink-fit preflight, preview, and batch export. |
| v1.4.0 (M14) | Extract text, checkbox states and native values, dropdowns, and radio groups from 1–200 filled AcroForm PDFs in the English or Arabic workbench. Review per-file errors and field schema warnings before downloading UTF-8 BOM CSV with formula-like cells escaped, Excel with explicit text cells, or an unsigned JSON receipt with SHA-256 hashes of every source PDF and both spreadsheets. Text in Excel and the receipt preserves the original Arabic diacritics, mixed-script punctuation, and leading zeros. |
| v1.3.0 (M13) | Choose a visible Excel worksheet in workbook order. The first visible tab opens by default. Drafts match the original workbook bytes and the exact active worksheet name. The custody manifest adds `sheetName` after a tab switch. For single-page templates, choose 2-up for the merged printable PDF to place two records on each A4 sheet with cut marks. Watermarks and vector QR stamps scale with the records, and the cover index points to the physical sheets. Multi-page templates use 1-up. Version 8 saves the layout in presets and draft settings. Preset versions 1–7 still import. |
| v1.2.0 (M12) | Add an optional per-record vector QR stamp to merged printable PDFs and flattened PDFs in ZIP. Set a corner, size, and roster pattern, then preview the selected row's QR locally. Choose the page language, English, Arabic, or both for the print cover. The bilingual cover puts headings and counts side by side over one shared index. Version 7 presets and local draft settings store the QR and cover language settings. Versions 1–6 still import. |
| v1.1.0 (M11) | Click a field in the PDF preview or activate it with the keyboard to focus the matching mapping control. Focusing that control highlights the field in the preview and opens its page when needed. Use locally computed row numbers, four-digit-minimum serials, or Gregorian dates with Western or Arabic-Indic digits in text fields and filenames. Version 6 presets and draft settings store the virtual mappings. Preset versions 1–5 still import. |
| v1.0.0 (M10) | Select specific ready rows or all ready matches across the filtered queue. The selection scopes ZIP, merged PDF and its cover index, preflight audit, and the custody manifest. The receipt records the export scope and original roster positions. Open the keyboard shortcuts dialog with `?` or its button, navigate matching rows with the arrow keys, and press `Esc` to return focus after closing the dialog. Added a strict release command that accepts the intended origin as an argument. |
| v0.9.0 (M9) | Download a separate JSON custody manifest with SHA-256 hashes of the source files and the PDFs generated by successful exports. Compare the full hashes to check that files match the bytes recorded in the receipt. Optionally print short source fingerprints on the merged PDF cover. The print-margin advisory identifies mapped widgets less than 9 pt from the nearest page edge, with the field, page, edge, and clearance. Ready rows remain available for export. |
| v0.8.0 (M8) | Inspect template field and widget dimensions, rotation, `/MaxLen`, and estimated Arabic and Latin text capacity before choosing a roster. Download the capacity report as CSV. Add an optional English, Arabic, or custom stamp to the merged printable PDF or flattened PDFs in ZIP. Version 5 mapping presets and local drafts save active watermark settings. Older presets still import. The local worker processes 500-row batches in chunks of 25 with progress and cancellation. |
| v0.7.0 (M7) | Preview and apply optional Arabic text cleanup or literal find and replace in selected roster columns. Undo the last transform. Set text-field alignment to Auto, Right (RTL), Left (LTR), or Center. Version 4 mapping presets save explicit alignment, and versions 1–3 still import. Save edits, applied cleanup summaries, mapping, and output settings to a local JSON draft and reopen it with the matching PDF, roster, and worksheet. The PDF preview has Fit, 100%, 125%, and 150% zoom and a page strip that marks flagged pages. The Arabic source hint displays `.xlsx` with its dot on the left. |
| v0.6.0 (M6) | Added an optional English or Arabic cover for the merged printable PDF. It includes a batch summary and a paginated index with the final filenames and page ranges. Mapping presets save the cover setting in version 3 and still read versions 1 and 2. The English and Arabic guides add an interactive synthetic ink-bounds specimen. The sample gallery shows four workflows, including the landscape badge to try the batch font-size suggestion. |
| v0.5.0 (M5-RC) | The queue shows why a filename was adjusted before export. Slash focuses search, and Escape cancels the current edit and restores focus. The Arabic page loads display fonts locally and defers packaged PDF font data until preflight. Added a release bundle check. |
| v0.4.0 (M4) | Added dropdown and radio mappings, optional flattened PDFs within ZIP, and preview navigation to the first page with a flagged field. |

## ملخص بالعربية

- **v2.7.0 (M27)** افتح «مقارنة الدفعات» بالعربية أو الإنجليزية لتصنيف ملفات PDF في أرشيفَي ZIP محليَّين حسب المسار النسبي وبصمة SHA-256. راجع قيم الحقول المحفوظة قبل التعديل وبعده، واطبع الملفات المعدّلة والمضافة وحدها. نزّل أرشيف إعادة الطباعة وتقارير CSV وJSON وملخّصًا ثنائي اللغة من صفحة واحدة بالأعداد والتوفير المقدّر في الورق. يتاح الوضع `--mode diff-batch` في الطرفية دون اتصال. [خطوات المقارنة والمثال الاصطناعي](README.md#مقارنة-الدفعات)
- **v2.6.0 (M26)** من «التحقق من بيانات الجدول»، حدّد الخلايا الإلزامية وافحص أرقام IBAN بفحص `Mod-97`، والتواريخ الميلادية بصيغة `ISO`، وعدد الأرقام، وصيغة البريد الإلكتروني، ومطابقة قائمة القيم المسموح بها. تعرض قائمة المراجعة وتقارير CSV وJSON رقم الصف وعنوان العمود والقاعدة وسبب الإخفاق. صحّح الصف من القائمة ليعود إلى الصفوف الجاهزة. جرّب مثال رواتب الخليج الاصطناعي أو أعد استخدام القواعد دون اتصال من ملف إعدادات بالإصدار 13. تظلّ الإصدارات من 1 إلى 12 قابلة للاستيراد. يوقف `fill --strict` تصدير الدفعة كاملة إذا أخفق صف. [خطوات التحقّق من بيانات الجدول](README.md#التحقق-من-بيانات-الجدول)
- **v2.5.0 (M25)** نزّل مسودات بريد ثنائية اللغة تُنشأ على جهازك، مسودة لكل صف جاهز في نطاق التصدير، مع إرفاق ملف PDF المطابق. راجع المستلمين وأسماء الملفات وبصمات SHA-256 في سجل التوزيع. احجب قيم حقول نصية محدّدة عند إعداد نسخ المراجعة، واعرف الحقول المحجوبة من بيان الحيازة. يمكنك تنفيذ العمليتين من الطرفية أيضًا. [مسودات البريد](README.md#مسودات-البريد-دون-اتصال) · [نسخ المراجعة](README.md#نسخ-المراجعة-المحجوبة)

- **v2.4.0 (M24)** ضع حتى أربعة سجلات من صفحة واحدة على ورقة A4 مع علامات قص الزوايا، وأضف خطوط القص في المنتصف أو اختر ترتيب القص والتكديس عند الحاجة. يعرض تقدير الطباعة التوفير مقارنةً بوضع سجل واحد لكل ورقة، مع احتساب صفحات الغلاف وملفات المجموعات. يصل التوفير إلى 75٪ عند امتلاء كل المواضع وإيقاف الغلاف. نزّل شهادة ما قبل الطباعة في صفحة واحدة بالعربية والإنجليزية. تضمّ بصمة SHA-256 للملف المدمج ونتيجة فحص ملاءمة الحقول في الصفوف المدرجة. احفظ خيارات السجلات الأربعة في الإصدار 12 أو شغّل `fill --imposition 4-up --print-certificate` محليًا. [شهادة ما قبل الطباعة](README.md#شهادة-ما-قبل-الطباعة)
- **v2.3.0 (M23)** افتح «مقارنة القوالب» لمراجعة إصدارين من قالب AcroForm ومعرفة الحقول المضافة والمحذوفة، وتغيّرات أنواع الحقول وأبعادها وحدود المحارف والخيارات. حدّد الحقول المتوافقة التي حلّت محلّ الحقول القديمة، ونزّل إعدادات الربط المُرحّلة بالإصدار نفسه من 1 إلى 11 بعد التحقّق من مراجعها. نزّل تقرير الترحيل بصيغتَي CSV وJSON مع بصمتَي القالبين، أو افتح القالب الجديد والإعدادات المُرحّلة في واجهة تعبئة PDF لفحص صفوف الجدول. تدعم أداة الطرفية وضع `--mode diff-template` دون اتصال. [خطوات مقارنة القوالب](README.md#مقارنة-القوالب)
- **v2.2.0 (M22)** افتح «قواعد التعبئة الشرطية» في واجهة التعبئة لكتابة نص أو مسحه، أو تغيير حالة خانة اختيار، أو تحديد خيار موجود في قالب PDF بناءً على قيم الجدول. غيّر ترتيب القواعد لتحديد أولوية تطبيقها على كل حقل، وراجع عدد الصفوف المطابقة والنتيجة في معاينة PDF. يحفظ الإصدار 11 القواعد بترتيبها ويتيح استخدامها في الطرفية دون اتصال عبر `--preset`. يظلّ استيراد الإصدارات من 1 إلى 10 متاحًا. يبيّن تقرير الفحص القاعدة المطبّقة على كل حقل شملته قاعدة. [خطوات استخدام القواعد](README.md#قواعد-التعبئة-الشرطية)
- **v2.1.0 (M21)** استخدم «تجميع الحزم» في الواجهة العربية أو الإنجليزية، أو `--mode packet` في الطرفية دون اتصال. رتّب من قالبَي AcroForm إلى أربعة، واربط حقول كل قالب بجدول CSV أو Excel مشترك، ثم صدّر ملف PDF مسطّحًا لكل شخص جاهز. إذا أخفق حقل في أي قالب، يتوقّف تصدير حزمة الشخص المعني وتبقى حزم الأشخاص الجاهزين متاحة. يمكنك إضافة فهرس بالعربية والإنجليزية يبيّن صفحات البداية الفعلية، وتجميع الملفات في مجلدات داخل ZIP بحسب عمود من الجدول، وحفظ بيان غير موقّع ببصمات SHA-256 للمصادر وملفات PDF الناتجة. [خطوات تجميع الحزم](README.md#تجميع-الحزم)
- **v2.0.0 (M20)** اختر شكل الأرقام وارتفاع السطر والحاشية الداخلية لكل حقل نصي مرتبط. يحافظ تحويل الأرقام على الأصفار البادئة ويظهر في قيمة الحقل وفي النص المرسوم. أضف ختم اعتماد ثنائي اللغة بإطار مرسوم وتاريخ إصدار إلى ملفات ZIP المسطّحة وملفات PDF المدمجة للطباعة، بما فيها ملفات المجموعات وتخطيط سجلّين لكل ورقة. عاين موضع الختم وغيّر الزاوية إذا تداخل مع حقل مرئي أو رمز QR. يحفظ الإصدار 10 إعدادات الحقول والختم في ملف يمكنك استخدامه في واجهة العمل أو في الطرفية عبر `--preset`. يستمر استيراد الإصدارات من 1 إلى 9.
- **v1.9.0 (M19)** انتقل مباشرةً إلى أطول نص مرتبط أو أصغر حجم خط مرسوم أو أول صف يحتاج إلى مراجعة. قارن صفَّين في الواجهة العربية أو الإنجليزية، مع معاينة PDF مستقلة لكل صف. يعرض الصف الجاهز أصغر حجم خط وأقصر مسافة بين حدود النص المرسوم وحافة حقله عند توفرهما. يعرض الصف الذي يحتاج إلى مراجعة القالب الأصلي ومشكلات الحقول. يتحدّث تقدير أوراق الطباعة عند تغيير الصفوف الجاهزة المحدّدة أو التخطيط أو الغلاف أو التجميع. يعرض التقدير الفرق بين سجل واحد وسجلين لكل ورقة عندما يدعم القالب التخطيطين، ويعرض إجمالي الملف المدمج وملفات المجموعات كلًّا على حدة.
- **v1.8.0 (M18)** شغّل دفعات PDF محليًا من مجلد الشفرة المصدرية باستخدام `npm run arabiform-cli --`. ينشئ `studio` قوالب ثنائية اللغة وجداولها، ويكتب `preflight` تقارير فحص CSV وExcel، وينتج `fill` أرشيفَي ZIP للملفات القابلة للتعديل والمسطّحة وملف PDF مدمجًا للطباعة. يقرأ `extract` قيم الحقول المحفوظة، ويقارن `verify` بايتات PDF أو سجلّ رمز QR ببيان دفعة غير موقّع. يتيح «أمر التشغيل المحلي» في واجهة العمل نسخ أمر `fill --strict` الذي يمنع التصدير عند إخفاق أي صف. رمز الخروج `0` للنجاح دون مشكلات، و`2` للتنبيه أو المنع، و`1` لخطأ في صيغة الأمر أو التعامل مع الملفات. [الأوامر والخيارات وصيغة البيان](docs/subsystems/cli-automation.md)
